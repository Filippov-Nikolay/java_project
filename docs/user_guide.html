User Guide

User Guide

Roles and access

  • Admin: manage users, subjects, groups, schedules, and journal records.
  • Teacher: manage homework, submissions, and assessments.
  • Student: view schedule, homework, submissions, and grades.

Login

  1. Open the login page.
  2. Enter email and password.
  3. After successful login, the system stores a JWT token in local storage and cookies.

Password recovery

  1. Use the Forgot password link.
  2. The system sends a recovery email with a reset link.
  3. Set a new password and log in again.

Homework and submissions

  • Teachers create homework and review submissions.
  • Students submit work before the deadline.

Schedule and journal

  • Schedule pages show lessons by day or week.
  • Journal pages display assessment records and attendance.

UI features

  • Notifications display success and error messages.
  • Theme toggle switches between light and dark modes.
