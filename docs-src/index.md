# Online Diary Documentation

This site documents the Online Diary course project. The system includes:
- Backend: Spring Boot REST API with JPA/Hibernate and Oracle DB.
- Frontend: Next.js UI.
- Email notifications via SMTP.

Read the following sections:
- @ref user_guide
- @ref technical_guide
- @ref deployment
- @ref code_structure

Quick start:
1. Configure the database and mail settings.
2. Run the backend.
3. Run the frontend.
